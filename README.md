# Dalpex Hub — descargas

Instalador de **Dalpex Hub**: la aplicación desde donde se compran, instalan y
abren las apps de Dalpex.

El Hub se actualiza solo: cuando sale una versión nueva, la baja en segundo
plano y te avisa para reiniciar. Este repositorio es de donde la baja.

## Descargar

**[Última versión](../../releases/latest)** → `Dalpex Hub Setup X.Y.Z.exe`

Windows 10/11 de 64 bits. Instalador de un solo click.

## Cómo entrar

La cuenta se crea en el Discord de Dalpex con `/registrar`, y con ese usuario
y contraseña entrás al Hub.

Si Windows avisa que el editor es desconocido, es porque el instalador todavía
no está firmado digitalmente: "Más información" → "Ejecutar de todas formas".
